# Проверка прототипа

Проверено 13 октября 2026 года.

## Подготовка GitHub Pages

Production-сборка с `base: '/walenza-website/'` проверена в локальном `vite preview`. QA повторён после перехода на HashRouter: все 22 маршрута, перезагрузка прямых ссылок, изображения, категории, диалог, мобильное меню и ширины 320–1440 px проходят. Дополнительно проверены якорь гардеробных, сохранение маршрута при пропуске меню и точный текст пометки о согласовании на каждой странице.

Фактическую публикацию нужно подтверждать отдельно: workflow должен завершиться успешно, публичный URL вернуть HTTP 200, а браузер загрузить интерфейс и ресурсы без ошибок.

## Первый локальный прототип

- `npm.cmd run build`: TypeScript и production-сборка Vite выполнены успешно.
- Браузер: отдельный временный профиль Microsoft Edge, Playwright.
- 22 маршрута: основные страницы, категории, карточки и неизвестные идентификаторы с экраном 404.
- Все 15 уникальных внутренних ссылок на страницы сопоставлены с проверенными маршрутами. Якоря категорий корпусной мебели ведут к существующим блокам.
- Сценарий: главная → кухни → угловые → карточка модели → окно обращения → Escape → назад с сохранённой категорией.
- FAQ раскрывается; мобильное меню открывается, ведёт к контактам и закрывается после перехода.
- Telegram на странице контактов открывает демонстрационный диалог; кнопка закрытия работает.
- На ширинах 320, 390, 800 и 1440 px основные страницы и карточки не имеют горизонтальной прокрутки.
- SVG-иллюстрации успешно загружаются. Снимки главной сохранены в `qa-output/home-1440.png` и `qa-output/home-390.png` (папка исключена из Git).
- Нет ошибок JavaScript, ошибок в консоли или HTTP-ответов 4xx/5xx при проверенных сценариях.
- На страницах нет форм, полей ввода и ссылок на неподтверждённые внешние контакты.

Проверка подтверждает готовность к первому просмотру, но не заменяет согласование контента, фирменного дизайна и условий работы. CMS, заявки и AI-интеграции не проверялись, поскольку не реализованы в этом этапе.

Для повторения браузерной проверки см. комментарий в `scripts/qa.cjs`. Playwright — инструмент QA, не зависимость клиентского приложения.
