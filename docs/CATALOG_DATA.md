# Каталоги и производители — 22 октября 2026

Источник данных — `src/data/content.ts`. Интерфейс каталога и структура маршрутов моделей сохранены.

- `catalogGroups`: справочник каталожных групп. Сейчас есть только `walenza`.
- `manufacturers`: справочник подтверждённых фабрик `{ id, name }`. Пока пуст: сведения о фабриках конкретных моделей не предоставлены. Бренды материалов хранятся отдельно и не становятся изготовителями кухонь.
- `Model.catalogGroupId`: обязательная принадлежность к одной каталожной группе.
- `Model.manufacturerId`: ссылка на запись `manufacturers` либо `null`, если изготовитель не установлен. У всех восьми моделей из сообщества салона — `null`: изготовитель по переданным материалам не установлен.
- `selectCatalogModels(groupId)`: единая точка отбора моделей группы. Основной каталог, счётчики направлений и рекомендации используют отобранные модели. Неизвестная группа даёт пустую подборку.

Для будущего расширения добавить подтверждённую фабрику в справочник, каталожную группу и реальные модели с уникальными во всём каталоге `id`. Несколько фабрик могут относиться к одной группе «Другие производители»: фабрика и группа — независимые признаки. Одна фабрика также может встречаться в разных группах.

`Kitchens` принимает `catalogGroupId`, по умолчанию `walenza`. Фильтры работают внутри группы; карточки показываются порциями по шесть без ограничения в 12 моделей. Детали остаются по `/kitchens/models/:id`, известный производитель выводится по справочнику, рекомендации ограничены группой модели. Названия, вводный текст, адрес возврата и сохранение выбранной группы в URL для будущей вкладки/страницы будут настроены при её реализации. Сейчас новых маршрутов, вкладок и моделей других фабрик нет.

Проверка: `scripts/qa-catalog.cjs` запускается против Vite dev server с теми же `PLAYWRIGHT_MODULE` и `QA_URL`, что `scripts/qa.cjs`. Временные данные другой группы создаются только в памяти отдельной браузерной вкладки и удаляются после проверки; в исходники и сборку они не записываются.

Восемь моделей, источники изображений, предварительное распределение и неподтверждённый остров описаны в `KITCHEN_MODELS_REVIEW.md`.
