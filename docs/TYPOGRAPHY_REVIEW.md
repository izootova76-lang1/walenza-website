# Локальная правка типографики и композиции

Дата локальной проверки: 13 октября 2026. После согласования пользователь разрешил отправку изменений в GitHub и публикацию через GitHub Pages. Итоговый статус deployment проверяется в GitHub Actions.

## Изменения

- `src/typography.css`: единая шкала — основной текст 16–18 px, меню и кнопки 15–16 px, описания карточек 15–16 px, характеристики 15–16 px, подписи от 13 px. Вторичный текст 15 px; служебные подписи 13 px.
- Мелкие исходные значения 8–12 px в `src/styles.css` заменены общими токенами. `src/main.tsx` подключает слой типографики после базового оформления.
- Крупные заголовки сохранены; скорректированы межстрочный интервал, межбуквенный интервал, баланс переносов и мобильный размер для узких экранов.
- Кнопка «Обсудить проект» в существующем меню выделена заливкой текущего фирменного зелёного цвета.
- Соседние секции используют общий вертикальный ритм. Суммарные отступы уменьшены; пространство вокруг изображений и размер карточек сохранены или увеличены.
- На планшетах меню раскрывается кнопкой. Карточки моделей на промежуточной ширине располагаются в двух колонках. Подписи и характеристики свободно переносятся; скрытая ранее подпись планировки снова доступна на планшете.
- Диалог ограничен высотой viewport с внутренней прокруткой. Кнопки имеют достаточную область нажатия, фокус клавиатуры усилен существующим цветом.
- Палитра, маршруты, данные, фильтры, изображения, порядок и состав секций, тексты и существующие сценарии не изменены.

## Проверка

`npm.cmd run build` выполнен успешно. Production-сборка проверена через локальный Vite preview.

`scripts/typography-review.cjs after`:

- 360, 390, 768, 1024, 1440 px: 11 представительных маршрутов и общие компоненты.
- Нет горизонтального переполнения, проверенных обрезанных подписей, текста меньше 13 px или наложений в шапке, меню, фильтрах, подписях карточек, заголовках секций и характеристиках.
- Меню читаемо, окно помещается в экран; нижняя кнопка доступна при прокрутке.
- Видимый фокус клавиатуры, Tab в нативном диалоге и закрытие Escape.
- Масштаб 200% проверен эмуляцией браузерного zoom: половина CSS-viewport и pixel ratio 2 для физических ширин 768, 1024, 1440 px. Проверены перестройка всех 11 маршрутов, прокрутка диалога и доступность его нижней кнопки. Ручной zoom через меню браузера не использовался.

`scripts/qa.cjs`: прежние 22 маршрута, 15 внутренних ссылок, фильтры, история, карточки, прямые ссылки и обновление, FAQ, якоря, окно обращения и мобильное меню проходят. Дополнительно сохранены проверки ширины 320 px. Ошибок JavaScript и форм сбора данных нет.

## Сравнение до / после

`qa-output/typography/comparison.html` — самостоятельный HTML-отчёт со встроенными снимками главной, каталога, модели, диалога и отдельным сравнением мобильного меню. Есть экраны 1440 и 390 px, главная целиком и примеры увеличения 200%. Отчёт открывается в браузере без сервера и не входит в сборку сайта.

Повторный запуск с внешне установленным Playwright:

```powershell
$env:PLAYWRIGHT_MODULE = 'абсолютный путь к модулю playwright'
$env:QA_URL = 'http://127.0.0.1:4178/walenza-website/'
node scripts/typography-review.cjs after
node scripts/build-typography-report.cjs
```

Исходные снимки находятся в `qa-output/typography/before`; не перезаписывать их после правки. Папка `qa-output` исключена из Git. Публикация должна выполняться только после отдельного разрешения.
