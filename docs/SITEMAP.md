# Карта сайта — 20 октября 2026

Все маршруты после `#`, например `/walenza-website/#/kitchens`.
В самостоятельном HTML — `WALENZA-preview.html#/kitchens`.

| Маршрут | Содержание |
| --- | --- |
| `/` | Первый экран; кухни / шкафы и гардеробные / дополнительные направления; материалы; проекты и отзывы; о салоне и этапы; полезные темы; акции; контакты |
| `/kitchens` | Общий обзор 6 из 12 кухонь, коллекции, планировка, остров, показать ещё, сброс |
| `/kitchens?collection=…&layout=…&island=…&shown=12` | Состояние выбора; параметры независимы и необязательны |
| `/kitchens/models/:id?return=…` | Детальный пример и возврат к выбранному каталогу; все прежние идентификаторы сохранены |
| `/furniture` | Шкафы, гардеробные и дополнительная мебель на одной странице |
| `/furniture#wardrobes`, `/furniture#dressing` | Основные категории хранения |
| `/furniture#additional` | Обзор дополнительных направлений |
| `/furniture#bedrooms`, `#living`, `#children`, `#hallways` | Спальни, гостиные, детские, прихожие — раскрывающиеся блоки без новых страниц |
| `/materials` | Четыре визуальные категории |
| `/materials?category=facades` | Фасадные материалы |
| `/materials?category=components` | Каркасы и комплектующие |
| `/materials?category=countertops` | Столешницы |
| `/materials?category=hardware` | Фурнитура; пятой категории нет |
| `/projects`, `/projects/:id` | Галерея и прежние детальные примеры |
| `/customers` | Компактные темы покупателям и FAQ без повторения условий |
| `/customers#order` | Как заказать и прежние четыре этапа |
| `/customers#payment` | Оплата |
| `/customers#delivery` | Доставка и установка |
| `/customers#warranty-care` | Гарантия и уход |
| `/promotions`, `/promotions/:id` | Прежний раздел и карточки акций |
| `/about` | Салон и будущая информация о команде |
| `/contacts` | Два телефона, адрес, часы, заявка, директор, MAX, Telegram и отдельный AI-помощник |
| `*` и неизвестные идентификаторы | 404 с возвратом |

Коллекции: `top`, `neoclassic`, `wood`, `character`, `art-deco`, `classic`.
Планировки: `straight`, `corner`, `u`. Остров: `with`, `without` либо любой.
Коллекции пересекаются; в каждой не менее двух разных примеров. Начальный обзор охватывает все шесть направлений. Старые `category=straight/corner/island` поддержаны как совместимость.

Основное меню содержит шесть пунктов. Главная открывается через логотип. Акции и О салоне сохранены во вторичной навигации, на главной и в подвале.

Заявка, директор, MAX, Telegram, AI — разные демонстрационные состояния одного диалога. Только телефонные ссылки имеют действующий `tel:`. Ссылка директора не выдумана.
