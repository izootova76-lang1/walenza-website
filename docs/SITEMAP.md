# Карта страниц

Пути в таблице — маршруты приложения. На GitHub Pages они следуют после `#`: например, `https://izootova76-lang1.github.io/walenza-website/#/kitchens`. Используется HashRouter; прямые ссылки и обновление страниц обслуживаются статическим `index.html`.

| Маршрут | Страница / поведение |
| --- | --- |
| `/` | Главная: двухуровневая шапка, первый экран, направления, модели, принципы, проекты, этапы, о салоне, отзывы, акции, контакты, подвал |
| `/kitchens` | Обзор и все демонстрационные модели кухонь |
| `/kitchens?category=straight` | Прямые кухни |
| `/kitchens?category=corner` | Угловые кухни |
| `/kitchens?category=island` | Кухни с островом |
| `/kitchens/models/:id` | Карточка модели; примеры: line, balance, rhythm |
| `/furniture` | Корпусная мебель: шкафы, гардеробные, примечание о будущих категориях |
| `/furniture#wardrobes` | Блок шкафов |
| `/furniture#dressing` | Блок гардеробных |
| `/projects` | Галерея демонстрационных проектов |
| `/projects/:id` | Карточка проекта; quiet-space, everyday-order |
| `/customers` | Предварительные этапы заказа, доставка, оплата, гарантия, уход, FAQ |
| `/promotions` | Демонстрационные акции |
| `/promotions/:id` | Карточка акции; season, collection |
| `/about` | Подтверждённый контекст бизнеса, места для истории и команды |
| `/contacts` | Регион, заглушки контактов, адреса, режима работы и карты |
| `*` | Страница 404 с возвратом на главную; неизвестные идентификаторы также отображают 404 |

Основное меню содержит все восемь страниц. На телефоне оно раскрывается кнопкой. Карточки моделей, проектов и акций целиком являются ссылками. Категории сохраняются в URL и поддерживают историю браузера. Неподдерживаемая категория отображает все модели.

Кнопки консультации открывают диалог с тремя способами связи. Реальных ссылок на телефон и мессенджеры нет до подтверждения реквизитов. Закрытие — кнопка, Escape или щелчок по фону.
