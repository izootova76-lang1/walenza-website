# Пробная вкладка «Заказ» — плитки этапов

Открыть `review/WALENZA-order-steps.html`: файл сразу показывает `/customers/pocket#order`, по умолчанию выбрана «Консультация». Сервер для просмотра не требуется. Публикации нет.

Изменено только содержимое «Заказа». Внешний кармашек, верхние вкладки, сворачивание, нижняя кнопка «Оставить заявку» и контекст обращения сохранены. Оплата, доставка, гарантия, уход и FAQ не менялись. CSS новых элементов добавлен отдельными правилами, прежние правила оформления не изменены.

- Семь кнопок в порядке существующего массива `steps`: на широком экране CSS Grid 12 колонок, первые четыре кнопки занимают по три колонки, остальные три — по четыре. На планшете две колонки, на телефоне до 600 px одна.
- Исходные названия и полные описания не переписывались. Краткая общая вводная над этапами убрана, чтобы сетка начиналась сразу под заголовком.
- Одна серая панель под всей сеткой показывает заголовок и текст выбранного этапа, имеет естественную высоту без внутренней прокрутки.
- Белые плитки с минимальной высотой 84 px на компьютере и 78 px на телефоне, серебристой границей и радиусом 6 px. Выбор отмечен серой подложкой и винной кромкой; клавиатурный фокус отдельно — внешней обводкой. При наведении меняется только фон.
- Иконки из существующего `LineIcon`, размер 24 px и толщина 1.3. Для согласования деталей и договора в ту же библиотеку добавлены контуры образцов и документа с подписью. Прежние иконки не изменены.
- `aria-pressed`, `aria-controls`, общий регион с названием и `aria-live`. Все кнопки доступны через Tab, Enter и Space. Нет декоративных номеров, плюсов и дополнительных раскрытий в плитках.
- На телефоне выбор подводит панель в видимую область плавной прокруткой `nearest`, только когда она за пределами экрана. Фокус остаётся на выбранной кнопке. При reduced-motion прокрутка выполняется без анимации.

Самое длинное исходное описание — «Согласование деталей»: «Выбираем фасады, цвета, материалы, столешницу, фурнитуру и внутреннее наполнение. Уточняем окончательную стоимость мебели и услуг.»

Проверки: `npm run build`, `scripts/qa-order-steps.cjs` на ширинах 320, 390, 768 и 1440 px, включая автономный файл. Все семь текстов сравнены с сохранённой исходной страницей `/customers#order`, проверены раскладка, полнота текста, клавиатура, видимость панели на телефоне, отсутствие горизонтального переполнения и reduced-motion. Отдельно проверено точное сохранение исходного кода остальных разделов и правил CSS; копии для сравнения в `qa-output/order-steps/`.
