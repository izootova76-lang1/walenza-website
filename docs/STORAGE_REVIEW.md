## Поведение и дальнейшее наполнение

- Данные — `src/data/storage.ts`: тип изделия, название, визуальное описание, изображения `facades` / `interior`, необязательный дополнительный ракурс.
- Компоненты — `src/components/StorageCard.tsx`: независимое состояние каждого изделия, переключение фотографией и двумя кнопками, доступные названия и `aria-pressed`, статус текущего вида. Никаких автопереключений.
- Для будущего изделия достаточно хотя бы одного изображения: при отсутствии пары показывается статичный вид без переключателя. Для каждого изделия требуется хотя бы один кадр. Не связывать фотографии разных изделий ради пары.
- Область изображения фиксирована 3:4, `object-fit: contain`: двери, нижние секции и ящики не обрезаются. Лёгкое растворение 180 мс отключается при reduced motion.
- Два шкафа видны сразу; кнопка показывает ещё три. Фокус переходит на первое добавленное изделие. На компьютере две карточки в ряд, на телефоне одна. Гардеробная — отдельный блок на той же странице.
- У Орбиты и Галереи есть нативное раскрытие дополнительного ракурса. Обращение передаёт рабочее название изделия в существующий демонстрационный диалог.
- Сохранены `/furniture#wardrobes`, `#dressing`, `#additional` и якоря дополнительных направлений. Новых страниц, форм, интеграций и публикации нет.
