# Пробное оформление крупными интерьерными плоскостями

Открыть `review/WALENZA-interior-planes.html`. Верхняя полоса сравнения предназначена только для согласования: «Текущее / Плоскости», переходы на главную, «Покупателям» и «О салоне». В обычный интерфейс сайта эта полоса не добавлена.

## Три разные композиции

- Главная: светлый фон и крупная более плотная серая плоскость справа, которая продолжается по странице за фотографиями и карточками. Блок материалов расположен на отдельной широкой горизонтальной плоскости. Никаких новых слоганов, подписей, номеров или фактур. Карусель и навигация сохранены.
- «Покупателям»: большая горизонтальная плоскость за заголовком и вводным текстом; отдельная зона фона за FAQ. Сам кармашек, плитки и читаемая панель остаются белыми с прежними серыми подложками и винными акцентами. Геометрия плоскостей не растягивает и не ограничивает раскрытый текст.
- «О салоне»: обратное распределение тонов — более плотная плоскость слева и светлая справа. Встреча с командой выделена широкой более светлой зоной. Фотографии и их исходная геометрия не изменялись.

Плоскости ровные, без зерна, песочных пятен, размытых разводов и блестящих лент. Стыки — тонкие серебристо-серые линии с очень слабой тенью. На телефоне вертикальные стыки убраны; сохранены крупные горизонтальные цветовые зоны.

## Включение и отключение

Оформление включается только при `?design=planes` на трёх адресах:

- `#/?design=planes`;
- `#/customers/pocket?design=planes#order`;
- `#/about?design=planes`.

Например, автономный файл с фрагментом `#/customers/pocket?design=planes#order` открывает пробных покупателей. Удаление параметра `design=planes` сразу возвращает прежний вид. Кнопка «Текущее» делает это автоматически, сохраняя страницу и выбранную вкладку. Остальные адреса, включая обычную страницу `/customers`, не получают оформление даже при переданном параметре.

Изменения изолированы в `src/interior-planes.css`; в `App.tsx` добавлена только проверка разрешённых маршрутов/параметра и класс оформления. Тексты и компоненты страниц не переделывались. Это обратимый эксперимент, а не распространение фона на весь сайт. Для полного удаления достаточно убрать импорт нового CSS и условный класс в App; сбрасывать остальные накопленные изменения проекта не нужно.

## Проверка

`npm run build`, `scripts/qa-interior-planes.cjs`: 360, 390, 768 и 1440 px, три страницы, затем автономный файл. Тексты, ссылки изображений и размеры основного содержимого сравниваются между режимами; они совпадают. Проверены загрузка всех изображений, отсутствие горизонтального переполнения, карусель, меню и смена его фотографии, кармашек, 45 строк тарифов доставки, уход и сворачивание. Раскрытая доставка сдвигает следующий блок без наложения.

Снимки и протоколы: `qa-output/interior-planes/`. Телефон проверен в браузерной эмуляции. Ничего не публиковалось, коммитов и отправки на GitHub Pages нет.
