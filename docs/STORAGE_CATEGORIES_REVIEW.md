# Категории шкафов · 26 октября 2026

Локальный файл: `review/WALENZA-storage-categories.html`. Полоса согласования над сайтом позволяет сравнить режим предварительного просмотра и вид для посетителя. Публикация не выполнялась.

## Структура

Внутри существующего раздела «Шкафы» добавлены категории в следующем порядке:

- Распашные шкафы (`hinged`).
- Шкафы-купе (`sliding`).

Обычный маршрут `/furniture#wardrobes` показывает только категории с подтверждёнными моделями. На данный момент видны только распашные. Запрос пустой категории через `doors=sliding` вне предварительного просмотра также возвращает существующую заполненную категорию без пустого блока.

Для согласования двух категорий используется `/furniture?preview=storage#wardrobes`. В нём доступно переключение на шкафы-купе с кратким сообщением об отсутствии подтверждённых моделей. Этот параметр — режим визуального согласования, а не средство авторизации. Ссылки сайта и меню его не добавляют. Выбор сохраняется в URL (`doors=hinged|sliding`), кнопка браузера «Назад» возвращает предыдущую категорию.

Пустая категория появится в обычной навигации только при наличии карточек с явно указанным `doorType: 'sliding'`. Тип не выводится автоматически из названия или общего вида фасада. Если тип будущей модели не подтверждён, поле не заполняется и карточка не попадает в категории автоматически.

## Проверка

Сборка `npm.cmd run build` успешна. `scripts/qa-storage-categories.cjs` проверяет автономный HTML на 360, 390, 768 и 1440 px: скрытие пустой категории, переключение в предварительном просмотре, клавиатуру, возврат браузера, переходы из меню, отдельную гардеробную и отсутствие горизонтальной прокрутки. Содержание и контрольные суммы всех изображений шести карточек совпадают с исходным снимком. Учтена существующая мобильная CSS-настройка, скрывающая подсказку о нажатии на фото.

Снимки: `qa-output/storage-categories/hinged-{1440,390}.png`, `sliding-preview-{1440,390}.png`. Результаты: `checks.json`.

Для наполнения категории шкафов-купе нужны подтверждённые модели, их изображения и сведения о конструкции. Новые модели, фотографии и характеристики не добавлялись.
