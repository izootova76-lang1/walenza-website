## Открыть без установки

Откройте `review/WALENZA-preview.html` в современном браузере. Это один самостоятельный файл со встроенными стилями, кодом и изображениями. Его можно переслать Анне; сервер для просмотра не нужен; Яндекс Карта и внешние ссылки требуют интернета. Телефонные ссылки работают по обычным настройкам устройства. Формы и мессенджеры не подключены.

Папка `review/` исключена из Git, потому что это генерируемый результат. Для повторной упаковки:

```powershell
npm.cmd ci
npm.cmd run build
node scripts/package-preview.cjs
```

Откройте адрес из терминала, обычно `http://127.0.0.1:5173/walenza-website/`.

## Структура и сценарии

- `src/App.tsx` — существующие маршруты плюс `/materials`, состояние демонстрационных обращений.
- `src/pages/Home.tsx` — главная-витрина с переходами, материалами, проектами/отзывами, этапами, полезными темами и контактами.
- `src/pages/Kitchens.tsx` — коллекции, независимые фильтры планировки и острова, восемь кухонь, подробный просмотр, возврат с выбранными фильтрами.
- `src/pages/Materials.tsx` — четыре визуальные категории и их примеры на одной странице.
- `src/pages/Sections.tsx` — шкафы и другая мебель, покупателям, проекты, акции, о салоне, контакты, 404.
- `src/components/` — шапка, подвал, карточки, этапы, FAQ и доступный нативный диалог.
- `src/data/content.ts` — редактируемые демонстрационные записи, предоставленные реквизиты и пустые неподтверждённые каналы.
- `src/assetUrl.ts` — базовый путь public-ресурсов и встроенные ресурсы самостоятельного HTML.
- `src/prototype.css` — локальные дополнения к существующей временной визуальной системе.
- `public/images/kitchens/` — 12 оригинальных SVG-композиций; `scripts/create-kitchen-visuals.cjs` воспроизводит их.
- `public/images/materials/` — четыре сгенерированные фотографии, происхождение и промпты в `docs/ASSET_NOTES.md`.

Структура прежних страниц сохранена; условные модели заменены восемью моделями салона с собственными идентификаторами. Старые URL с `category=straight`, `category=corner`, `category=island` также открываются. Используется HashRouter.

Главное меню: Кухни · Шкафы и мебель · Проекты · Материалы · Покупателям · Контакты. О салоне и Акции доступны во вторичной навигации и из главной.

## Проверка

`scripts/qa.cjs` использует внешний Playwright и отдельный временный профиль Edge. Никакие данные не отправляются, звонки не инициируются. Пример для подготовленной среды:

```powershell
$env:PLAYWRIGHT_MODULE = 'абсолютный путь к модулю playwright'
$env:QA_URL = 'http://127.0.0.1:4178/walenza-website/'
node scripts/qa.cjs
```

Сценарии включают 30 маршрутов, все 13 моделей, 84 сочетания фильтров, материалы, якоря покупателям, дополнительные направления, контекст заявки, мобильное меню, диалог, ширины 360–1440 px и эмуляцию масштаба 200%. Итог и ограничения описаны в `docs/VERIFICATION.md`.
