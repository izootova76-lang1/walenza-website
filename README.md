# WALENZA — архитектурный прототип

Кликабельная витрина мебельного салона на React, TypeScript, Vite и React Router. Предварительная версия для согласования структуры и наполнения.

- Исходники: https://github.com/izootova76-lang1/walenza-website
- Адрес GitHub Pages: https://izootova76-lang1.github.io/walenza-website/
- Подготовка и порядок публикации: [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Запуск

Нужен Node.js 22.12+ (или поддерживаемая версия новее), npm и доступ к npm при первоначальной установке.

```powershell
cd 'C:\КУРС ВАЙБКОДИНГ\сайт лендинг\walenza'
npm.cmd install
npm.cmd run dev
```

Откройте Local URL из терминала (обычно http://127.0.0.1:5173/walenza-website/). На Windows указан `npm.cmd`, чтобы запуск не зависел от политики выполнения PowerShell. Для новой копии репозитория используйте `npm.cmd ci`.

```powershell
npm.cmd run build
npm.cmd run preview
```

`build` проверяет TypeScript и создаёт `dist/`. `preview` показывает собранную версию (обычно http://127.0.0.1:4173/walenza-website/). Не открывайте `index.html` двойным щелчком: приложение запускается через Vite. Если порт занят, используйте URL, напечатанный Vite.

## Структура

- `src/App.tsx` — маршруты и состояние демонстрационного окна обращения.
- `src/components/` — шапка, мобильная навигация, подвал, карточки, этапы, FAQ.
- `src/pages/` — главная и страницы разделов, включая карточки и 404.
- `src/data/content.ts` — типы и демонстрационные данные; `contentRepository` — точка чтения для будущего адаптера CMS.
- `src/styles.css` — адаптивное оформление.
- `public/images/` — оригинальные локальные SVG-иллюстрации, не фотографии продукции WALENZA.
- `docs/` — карта сайта, отсутствующий контент, решения и дальнейшие задачи.
- `scripts/qa.cjs` — проверка браузерных сценариев с установленным Playwright; инструкция внутри файла.

## Что проверить при просмотре

Главная → Кухни → категория → модель → демонстрация обращения. Затем: Корпусная мебель → Шкафы / Гардеробные; Проекты → карточка; Покупателям → этапы и FAQ; Акции → карточка; Контакты → телефон / MAX / Telegram. На узком экране меню открывается отдельной кнопкой.

## Ограничения этапа

Все модели, проекты, отзывы, акции и иллюстрации обозначены как демонстрационные. Материалы, цены, сроки, реальные отзывы, адрес и контакты не выдуманы. Этапы заказа предварительные. Нет действующих форм, сбора персональных данных, сервера, базы, CMS, оплаты, аналитики и AI-интеграций. Для контента и изображений приложение не обращается к внешним ресурсам.

Для GitHub Pages используется `HashRouter`: страницы имеют адреса вида `/walenza-website/#/kitchens`. Прямые ссылки и обновление страницы не требуют серверного SPA fallback. `base` Vite и `assetUrl` сохраняют изображения, стили и скрипты внутри `/walenza-website/`. Автоматическая публикация настроена в `.github/workflows/deploy-pages.yml` при изменениях ветки `main` и по ручному запуску.
