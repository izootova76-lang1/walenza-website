# WALENZA — прототип для согласования, 20 октября 2026

React, TypeScript, Vite, React Router. Существующий проект доработан для согласования. Последующей командой пользователь разрешил публикацию обновления в существующем GitHub Pages.

## Открыть без установки

Откройте `review/WALENZA-preview.html` в современном браузере. Это один самостоятельный файл со встроенными стилями, кодом и изображениями. Его можно переслать Анне; сервер и интернет для просмотра не нужны. Телефонные ссылки работают по обычным настройкам устройства. Формы и мессенджеры не подключены.

Папка `review/` исключена из Git, потому что это генерируемый результат. Для повторной упаковки:

```powershell
npm.cmd ci
npm.cmd run build
node scripts/package-preview.cjs
```

## Обычный локальный запуск

Требуется Node.js 22.12+ или поддерживаемая более новая версия.

```powershell
cd 'C:\КУРС ВАЙБКОДИНГ\сайт лендинг\walenza'
npm.cmd ci
npm.cmd run dev
```

Откройте адрес из терминала, обычно `http://127.0.0.1:5173/walenza-website/`.

```powershell
npm.cmd run build
npm.cmd run preview
```

`build` проверяет TypeScript и собирает `dist/`. Предпросмотр сборки: обычно `http://127.0.0.1:4173/walenza-website/`.

## Структура и сценарии

- `src/App.tsx` — существующие маршруты плюс `/materials`, состояние демонстрационных обращений.
- `src/pages/Home.tsx` — главная-витрина с переходами, материалами, проектами/отзывами, этапами, полезными темами и контактами.
- `src/pages/Kitchens.tsx` — коллекции, независимые фильтры планировки и острова, 12 кухонь, подробный просмотр, возврат с выбранными фильтрами.
- `src/pages/Materials.tsx` — четыре визуальные категории и их примеры на одной странице.
- `src/pages/Sections.tsx` — шкафы и другая мебель, покупателям, проекты, акции, о салоне, контакты, 404.
- `src/components/` — шапка, подвал, карточки, этапы, FAQ и доступный нативный диалог.
- `src/data/content.ts` — редактируемые демонстрационные записи, предоставленные реквизиты и пустые неподтверждённые каналы.
- `src/assetUrl.ts` — базовый путь public-ресурсов и встроенные ресурсы самостоятельного HTML.
- `src/prototype.css` — локальные дополнения к существующей временной визуальной системе.
- `public/images/kitchens/` — 12 оригинальных SVG-композиций; `scripts/create-kitchen-visuals.cjs` воспроизводит их.
- `public/images/materials/` — четыре сгенерированные фотографии, происхождение и промпты в `docs/ASSET_NOTES.md`.

Все старые страницы и идентификаторы `line`, `balance`, `rhythm` сохранены. Старые URL с `category=straight`, `category=corner`, `category=island` также открываются. Используется HashRouter.

Главное меню: Кухни · Шкафы и мебель · Проекты · Материалы · Покупателям · Контакты. О салоне и Акции доступны во вторичной навигации и из главной.

## Проверка

`scripts/qa.cjs` использует внешний Playwright и отдельный временный профиль Edge. Никакие данные не отправляются, звонки не инициируются. Пример для подготовленной среды:

```powershell
$env:PLAYWRIGHT_MODULE = 'абсолютный путь к модулю playwright'
$env:QA_URL = 'http://127.0.0.1:4178/walenza-website/'
node scripts/qa.cjs
```

Сценарии включают 29 маршрутов, все 12 моделей, 84 сочетания фильтров, материалы, якоря покупателям, дополнительные направления, контекст заявки, мобильное меню, диалог, ширины 360–1440 px и эмуляцию масштаба 200%. Итог и ограничения описаны в `docs/VERIFICATION.md`.

## Границы

Название и цвета временные. Визуалы, модели, материалы, проекты, отзывы и акции демонстрационные. Телефоны, адрес и часы получены из задания, не из независимой проверки. MAX, Telegram, контакт Анны и AI-бот не подключены. Нет формы сбора данных, аналитики, CMS, сервера, базы и расчёта стоимости.

Существующий workflow GitHub Pages не изменён. Push в `main` запускает публикацию автоматически. Адрес просмотра: https://izootova76-lang1.github.io/walenza-website/. Статус конкретной версии проверяется в GitHub Actions и по ресурсам опубликованной сборки.
